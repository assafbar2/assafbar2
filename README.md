## Shipping

- **[The Support Machine](https://github.com/assafbar2/the-support-machine)** — Field guide + executable AI skill for support that isn't chatbot theater. [site](https://assafbar2.github.io/the-support-machine/)
- **[Greenroom](https://github.com/assafbar2/greenroom)** — For builders (especially hackathons): multi-model panel that argues blind—you keep the ledger.
- **[Agent Switchboard](https://github.com/assafbar2/agentswitchboard.dev)** — Curated agents/MCP directory with weekly catalog drops. [live](https://agentswitchboard.dev)
- **[CALL-E](https://github.com/assafbar2/customer-success-voice-signal-hackathon)** — Voice agents that ring the CS owner, not the customer. [live](https://assafbar2.github.io/customer-success-voice-signal-hackathon/)
- **[Vessel](https://github.com/assafbar2/Vessel)** — Therapeutic writing for self care (EMDR-inspired).
- **[NowPath](https://github.com/assafbar2/NowPath)** — Self care: set and follow a path back to now. [live](https://nowpath-bice.vercel.app)
- **[Ada Quest](https://github.com/assafbar2/ada-quest)** — Educational Ada/SPARK missions that teach systems safety through small bugs. [live](https://assafbar2.github.io/ada-quest/)
- **[Ada Revival](https://github.com/assafbar2/ada-revival)** — In-browser Ada playground that proves code correct (SPARK), plus an MCP kit so assistants can write safer systems code.
- **[Flux](https://github.com/assafbar2/flux-hackathon-2026)** — Hackathon project: onboards new engineers from how the team actually works—not the stale wiki.
- **[Conflict: 2027](https://conflict-2027.vercel.app/)** — Political sim where your actions push toward peace in the Middle East. Source private.
- **[barnirhired](https://barnirhired.com/)** — Helps GTM and technical candidates gauge role fit and prep for hiring at companies that hire well.
