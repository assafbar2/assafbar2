## The Lab

Not everything here is for a boardroom. Built because I couldn't not build them — the instinct is the same one I bring to the work.

- **[Conflict: 2027](https://conflict-2027.vercel.app/)** — a 48-turn political simulation where a sustainable peace is winnable and genuinely hard. Built at an AWS Loop Hacking hackathon.
- **[Vessel](https://github.com/assafbar2/Vessel)** — a therapeutic writing environment inspired by EMDR, built to help difficult thoughts move instead of harden.
- **[NowPath](https://nowpath-bice.vercel.app)** — your path back to now. Offline-first, on-device, no accounts and no analytics.
- **[Ada Revival](https://github.com/assafbar2/ada-revival)** and **[Ada Quest](https://assafbar2.github.io/ada-quest/)** — an in-browser Ada/SPARK proving ground, interactive missions, and an MCP kit so AI assistants can write safer systems code.
- **[Agent Switchboard](https://agentswitchboard.dev)** — where humans and agents find each other, signal what they need, and show what they can do.
- **[Ground Truth](https://ground-truth-gamma.vercel.app)** — one topic, five editorial perspectives, no feed and no algorithmic addiction loop. Built by Rune (see below).
- **[Composer Muse](https://assafbar2.github.io/composer-muse/)** — a concert-hall playground for generating original music while learning how the classical composers actually worked.
- **[Logo v2](https://github.com/assafbar2/logo-v2)** — a remake of the Logo turtle system that taught a generation to program.
- **[Gram Reaper](https://github.com/assafbar2/gram-reaper)** — an open-source protein tracker with natural-language AI parsing.
- **[Sentry Playground](https://playground-eight-lovat.vercel.app)** — a React 19 app instrumented with the Sentry SDK, for exercising error monitoring somewhere real.

## Rune

Rune is my engineering agent. [Ground Truth](https://github.com/assafbar2/ground-truth) was its first project, built end to end — I set the direction and reviewed, Rune wrote and shipped it.

I mention it because it's the whole thesis in one repo. The interesting question about AI is not whether it can write code; it's what the human does instead, and how you stay accountable for output you did not type. I'd rather say plainly that an agent I built and supervise wrote a thing here than let you assume otherwise.
