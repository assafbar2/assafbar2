## What I Build

I work where human judgment meets practical AI infrastructure. The through-line is simple: replace vague transformation talk with tools, rituals, and operating models people can actually use.

| Track | What It Means | Examples |
| --- | --- | --- |
| Human OS | Tools for the person in the loop: reflection, resilience, writing, health, privacy, and judgment. | Vessel, Gram Reaper, Emotions Soup |
| AI Stack | Agents and interfaces that turn scattered context into grounded action. | Flux, Ground Truth, agent tooling |
| Execution | Operating models for customer-facing teams, FTE planning, and the AI transition. | The Support Machine, barnirhired, GiFOC, workshops |
